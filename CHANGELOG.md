# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 1.0.0

### Added

* Initial stable release.
* Dependency registration and resolution.
* Singleton dependency registration.
* Lazy singleton dependency registration.
* Factory dependency registration.
* Generic type-safe dependency resolution.
* Dependency lifecycle management.
* Dependency disposal support.
* Clear and simple API for dependency injection in Dart and Flutter applications.

### Documentation

* Added package documentation.
* Added usage examples.
* Added API usage guidelines.
